About Star Log

A science exploration project built for curious minds.

Star Log brings public astronomy resources into one responsive interface. When online, it fetches current astronomy pictures and telescope images from NASA's public endpoints. The service worker helps cache the site for offline reopening; new discoveries require an internet connection.

Science note: NASA APOD features different subjects and contributors. Not every APOD image is from Hubble. Read each item's explanation and source to learn which telescope or observatory was used.
